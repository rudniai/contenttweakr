2. Description of Service

CommentScope is a browser extension that extracts publicly visible comments from Instagram posts and reels, and exports them as CSV and/or JSON files. The Extension offers two modes:

  • Page Mode: Extracts comments from the Instagram page you are currently viewing.
  • URL Mode: Extracts comments by making authenticated requests to Instagram's web API using your existing browser session.

All processing occurs locally in your browser. No data is transmitted to CommentScope's servers.
