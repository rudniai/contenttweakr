# ContentTweakr

AI-powered content repurposing tool. Paste any content, get optimized versions for every platform.

## Stack
- Next.js 14 (App Router)
- Supabase (Auth + DB)
- Tailwind CSS
- Azure OpenAI (GPT-4)

## Features
- Paste blog post / article / long text
- Get 10+ ready-to-post tweets, LinkedIn posts, Instagram captions
- Freemium model (5 free, then paywall)
